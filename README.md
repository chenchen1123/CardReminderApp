# 📇 卡片提醒助手 (Card Reminder App)

一款轻量、极简且高效的 Android 卡片管理与周期续期工具，基于现代化 **Jetpack Compose + Material 3** 构建。专注于帮助用户安全管理各类银行卡、境外电话卡、邮箱、账号等具有周期性维护需求的卡片。

---

## 🌟 核心功能一览

### 1. 🗂️ 卡片分类与可视化概览
* **分类体系**：支持银行卡、电话卡、邮箱、账号、其他等预设分类。
* **横向卡片展示**：首页按分类陈列卡片，并实时标注分类下的总卡片数与待处理卡片数。
* **临期/超期视觉标签**：
  * 🔴 **已过期**：超期卡片显式标注红色“已过期”标签。
  * 🟠 **即将到期（≤ 3天）**：醒目标注橙色“剩 X 天”预警。

### 2. ⚡ 一键“更新”顺延续期
* **无需繁琐改日期**：每张卡片配置了独立的**提醒/续期间隔**（如 30 天、180 天或自定义天数）。
* **动态对比度按钮**：卡片上提供高对比度自适应配色的“更新”按钮（深底配白亮钮，浅底配深色实心钮）。
* **自动计算到期日**：点击“更新”并确认后，系统自动基于当前到期日 + 间隔天数计算出新日期并一键更新。

### 3. 📝 极简录入与交互优化
* **点按空白失去焦点**：新增与编辑页面点击屏幕任意空白非输入区域，自动收起软键盘并保存当前输入数据。
* **个性化卡片定制**：支持内置主题色选择与相册自定义卡片背景图（内置沙盒持久化拷贝）。
* **快速检索与排序**：支持卡片置顶、按分类筛选以及按到期日期升序/降序查看。

### 4. 📊 Excel (CSV) 导入导出与快照回滚
* **标准表格导出**：一键生成带有 UTF-8 BOM 的标准 `.csv` 文件，直接兼容 Excel 打开且不乱码，支持系统级一键分享。
* **空模板下载**：内置“下载导入模板”功能，列明规范表头（`名称,卡号,分类,到期日期,提醒间隔天数,备注`），降低用户录入出错率。
* **智能导入选择**：
  * **合并追加**：基于卡片名称与卡号自动查重，重复的覆盖更新，新卡片自动追加。
  * **清空覆盖**：清空手机现有数据并完全导入表格数据。
* **自动安全快照（回滚机制）**：在执行任何导入操作前，系统自动在本地生成快照备份，支持随时“从上一次历史备份中恢复”。

### 5. 🎨 动态外观系统
* 内置 **默认明亮**、**深色夜间**、**静谧海洋** 以及 **动态炫彩（流光渐变）** 四套专属主题风格。

## 🛠️ 技术架构与栈说明

* **开发语言**：Kotlin
* **UI 框架**：Jetpack Compose (Material 3)
* **图片加载**：Coil Compose (`io.coil-kt:coil-compose`)
* **本地存储**：`SharedPreferences` + 本地 JSON 结构化序列化
* **编译规范**：
  * `compileSdk = 34` / `targetSdk = 34`
  * `minSdk = 24` (支持 Android 7.0 及以上所有设备)
  * Java 17 / JVM Target 17
  * 强制 Debug/Release 签名统一，规避安装签名冲突

## 📋 CSV 表格导入导出格式规范

如需通过电脑批量制作或编辑卡片数据并导入手机，请遵循以下 CSV 格式：

```csv
名称,卡号,分类,到期日期,提醒间隔天数,备注
"招商银行信用卡","6225888899990000","银行卡","2026-12-31",30,"每月账单日5号"
"香港手机卡","+852 98765432","电话卡","2026-10-15",180,"需每半年发一条短信保号"
后续维护与二次开发注意事项
零闹钟与轻量化策略：

软件已彻底剔除系统原生闹钟与复杂通知权限调用，避免因国产 Android 系统省电策略杀后台导致的通知失效。

日期推进完全由用户在“列表”模块点击“更新”主动触发或由启动时差值算法计算。

相册图片存储机制：

从相册选取卡片背景图时，文件会被自动拷贝到应用内部私有沙盒目录（context.filesDir）。导出 CSV 时不包含图片文件本身，重装或更换设备后需重新设置相册背景。

签名冲突防范：

在 app/build.gradle.kts 中已配置 debug 与 release 统一使用标准调试证书签名。若后续需要正式发布到各大应用商店，请在 signingConfigs 中配置正式的 .jks 证书。
