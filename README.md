# 📇 贾维斯 - 卡片提醒助手 (Card Reminder App) v2.1

一款轻量、安全、高效且现代化的 Android 卡片管理与周期续期工具。基于 **Jetpack Compose + Material 3** 构建，专注于帮助用户安全管理各类银行卡、手机卡、会员卡、邮箱、账号等具有周期性维护与续期提醒需求的卡片数据。

---

## 🌟 核心功能特色 (v2.1)

### 1. 🔔 系统通知栏本地强提醒 (AlarmManager Notification)
* **智能到期调度**：卡片保存或更新后，系统通过 `AlarmManager` 自动计算并调度到期前 3 天、到期前 1 天及到期当天的本地强提醒。
* **横幅通知与跳转**：到期触发时在顶部通知栏发送高优先级响铃/悬浮通知，点击通知栏可直接打开 APP 查看对应卡片。

### 2. 🔒 敏感数据 AES 硬件加密 (Encrypted Storage)
* **隐私安全防护**：对卡号等敏感数据在存入本地 JSON 及 SharedPreferences 时应用 AES 算法进行加密脱敏保护，防止设备脱机或 Root 后数据泄露。

### 3. 📷 拍卡 / 图像 OCR 智能识别卡号
* **快捷识别填号**：在新增与编辑卡片时提供“相机识别”按键，上传或拍摄卡片照片后，系统自动通过图像字符模式匹配智能提取 13-19 位卡号并填入输入框，省去手动输入的麻烦。

### 4. 🔍 常用卡片一维条形码与二维码生成核销 (Barcode & QR Generator)
* **线下扫码核销**：在列表卡片项上点击二维码图标，即可全屏清晰渲染该卡号对应的 **Code128 一维条形码** 与 **QR 二维码**，方便线下直接出示给商家扫描枪扫码核销。

### 5. 🖼️ 自定义多图附件与全屏左右滑动大图预览
* **多图附件支持**：在卡片新增与编辑模块中，支持添加多张相册图片（如发票、账单、合同、凭证）。
* **手势全屏大图预览**：点击缩略图即可调起全屏弹窗，支持手势**左右滑动轮播查看**，并实时显示页码与关闭图标。

### 6. 🗂️ 首页分类与智能到期排序
* **多维度分类**：内置银行卡、电话卡、邮箱、账号、其他等预设分类，并支持用户自定义分类。
* **智能到期升序**：首页分类内部的卡片自动按照**到期时间升序**排列，到期越早、越紧急需要处理的卡片自动排在最前面/最左侧。

### 7. 🛡️ 列表卡片手势操作与滑动修改二级确认
* **手势滑动修改与删除**：列表支持向左滑动删除卡片、向右滑动编辑卡片。
* **二级确认防误触**：向右滑动修改卡片时，会自动弹出**二级确认对话框**，询问“是否确定修改卡片信息”，避免日常滑动误触。

### 8. 📦 全量图片 zip 备份与 Excel (CSV) 导入导出
* **全量数据+图片 ZIP 备份**：支持将所有卡片文本数据与绑定的背景图、图片附件完整打包压缩为 `.zip` 备份文件，换机时导入 zip 即可完美恢复数据与图片文件。
* **Excel (CSV) 交互**：支持一键导出带 UTF-8 BOM 标记的标准 `.csv` 表格，直接用 Excel 打开不乱码，并提供空白导入模板下载。

## 🛠️ 技术架构说明

* **UI 框架**：Jetpack Compose (Material 3)
* **开发语言**：Kotlin
* **图片与二维码**：Coil Compose (`io.coil-kt:coil-compose`) + Canvas 矩阵绘制
* **定时与通知**：AlarmManager + NotificationManager + BroadcastReceiver
* **数据加密与持久化**：AES 算法 + SharedPreferences + 本地 JSON 结构化存储
* **构建与 CI/CD**：Java 17 / JVM Target 17 / `compileSdk = 34` / GitHub Actions

## 🚀 构建与部署说明

1. 克隆本项目：
   ```bash
   git clone https://github.com/chenchen1123/CardReminderApp.git
   ```
2. 使用 Android Studio (2023.3+) 打开项目。
3. 执行 Gradle 构建：
   ```bash
   ./gradlew assembleDebug
   ```
