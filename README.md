# 📇 贾维斯 - 卡片提醒助手 (Card Reminder App) v2.0

一款轻量、安全、高效且现代化的 Android 卡片管理与周期续期工具。基于 **Jetpack Compose + Material 3** 构建，专注于帮助用户安全管理各类银行卡、手机卡、会员卡、邮箱、账号等具有周期性维护与续期提醒需求的卡片数据。

---

## 🌟 核心功能特色 (v2.0)

### 1. 🗂️ 首页分类与智能到期排序
* **多维度分类**：内置银行卡、电话卡、邮箱、账号、其他等预设分类，并支持用户自定义分类。
* **智能到期升序**：首页分类内部的卡片自动按照**到期时间升序**排列，到期越早、越紧急需要处理的卡片自动排在最前面/最左侧。
* **临期/超期视觉标签**：
  * 🔴 **已过期**：超期卡片显式标注红色“已过期”标签。
  * 🟠 **即将到期（≤ 3天 / 30天）**：醒目标注“剩 X 天”预警提示。

### 2. 🖼️ 自定义多图附件与全屏左右滑动大图预览
* **多图附件支持**：在卡片新增与编辑模块中，支持添加多张相册图片（如发票、账单、合同、凭证）。
* **手势全屏大图预览**：点击缩略图即可调起全屏弹窗，支持手势**左右滑动轮播查看**，并实时显示页码与关闭图标。

### 3. 🛡️ 列表卡片手势操作与滑动修改二级确认
* **手势滑动修改与删除**：列表支持向左滑动删除卡片、向右滑动编辑卡片。
* **二级确认防误触**：向右滑动修改卡片时，会自动弹出**二级确认对话框**，询问“是否确定修改卡片信息”，避免日常滑动误触。
* **快捷卡号隐藏与复制**：卡号默认遮罩显示，提供一键打码/明文切换与剪贴板一键复制功能。

### 4. 📦 全量图片 zip 备份与 Excel (CSV) 导入导出
* **全量数据+图片 ZIP 备份**：支持将所有卡片文本数据与绑定的背景图、图片附件完整打包压缩为 `.zip` 备份文件，换机时导入 zip 即可完美恢复数据与图片文件。
* **Excel (CSV) 交互**：支持一键导出带 UTF-8 BOM 标记的标准 `.csv` 表格，直接用 Excel 打开不乱码，并提供空白导入模板下载。
* **智能导入判断**：导入时自动识别 `.zip` 或 `.csv` 格式，提供“合并追加”与“清空覆盖”双模式。

### 5. 🔒 生物识别安全锁与 📜 操作历史回滚
* **生物识别锁**：支持指纹/面容解锁防护，开启后启动 APP 需进行身份验证。
* **操作历史与快照恢复**：自动记录最近 100 条卡片增删改查操作快照，随时支持回滚恢复至任意历史时间节点的状态。

### 6. 🎨 丰富的外观主题与多语言支持
* **多款精美主题**：内置默认明亮、深色夜间、静谧海洋、深空星海、极光星穹、落樱物语、赛博霓虹及动态流光渐变等主题。
* **国际化语言**：支持简体中文、繁體中文、English、日本語、Português。

## 🛠️ 技术架构说明

* **UI 框架**：Jetpack Compose (Material 3)
* **开发语言**：Kotlin
* **图片加载**：Coil Compose (`io.coil-kt:coil-compose`)
* **异步与手势**：Kotlin Coroutines + Foundation Pager (HorizontalPager)
* **数据持久化**：SharedPreferences + 本地 JSON 结构化存储 + 本地文件沙盒
* **构建与 CI/CD**：
  * Java 17 / JVM Target 17
  * `compileSdk = 34` / `targetSdk = 34` / `minSdk = 24`
  * 集成 GitHub Actions 自动化编译打包工作流

## 📋 CSV 表格导入导出格式规范

如需通过电脑批量制作或编辑卡片数据并导入手机，请遵循以下 CSV 格式：

```csv
名称,卡号,分类,到期日期,提醒间隔天数,备注
"招商银行信用卡","6225888899990000","银行卡","2026-12-31",30,"每月账单日5号"
"香港手机卡","+852 98765432","电话卡","2026-10-15",180,"需每半年发一条短信保号"
```

## 🚀 构建与部署说明

1. 克隆本项目：
   ```bash
   git clone https://github.com/chenchen1123/CardReminderApp.git
   ```
2. 使用 Android Studio (2023.3+) 打开项目。
3. 执行 Gradle 构建：
   ```bash
   ./gradlew assembleDebug
   ```
