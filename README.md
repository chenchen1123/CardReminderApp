# CardReminderApp
卡管理软件
1. 产品概述
产品名称：卡片提醒助手 (CardReminderApp)
产品定位：一款极简、高隐私、本地化的 Android 卡片与账号到期管理工具。
核心目标：提供清晰的分类卡片管理，结合 Android 精准闹钟，确保用户重要的银行卡、电话卡、账号等在到期前得到及时提醒。
2. 核心架构与功能模块
项目的底部导航栏分为四个主 Tab 页面：

│                    底部导航 (NavigationBar)               │
├─────────────┬─────────────┬─────────────┬───────────────┤
│   1. 首页   │   2. 列表   │   3. 新增   │    4. 我的    │
└─────────────┴─────────────┴─────────────┴───────────────┘
模块一：首页（分类浏览）
展示方式：按分类（银行卡、电话卡、邮箱、账号、其他）分组展示。
交互体验：
每个分类下的卡片采用 水平横向滑动（LazyRow） 浏览。
右上角显示当前分类下的卡片数量（如 3张）。
点击任意卡片可直接进入该卡片的编辑页面。
模块二：卡片列表
列表视图：垂直纵向滑动展示所有卡片。
交互与操作：
展开备注：默认单次点击卡片可展开/折叠查看详细备注（未展开时提示 点击卡片查看备注...）。
滑动手势：
右划（从左向右）：触发 编辑 操作。
左划（从右向左）：触发 删除确认弹窗（防止误触）。
卡片置顶：点击卡片右上角置顶图标，置顶卡片高亮并排在列表最前。
筛选与排序：顶部 TopBar 提供“按分类筛选”和“按到期时间升/降序”功能。

3. 技术设计与关键稳定性规范
为了防止后续开发引入新的崩溃或数据丢失问题，开发需 严格遵循 以下技术规范：
3.1 数据持久化 (Storage)
机制：采用 SharedPreferences 配合 JSONArray/JSONObject 实现本地 JSON 序列化。
防御性编程：颜色解析必须使用安全的 parseColorHex 函数（去除 0x / # 前缀后解析），彻底杜绝 NumberFormatException。
3.2 闹钟与通知架构 (Alarm & Notification)
唤醒机制：使用 AlarmManager.setExactAndAllowWhileIdle 结合 RTC_WAKEUP，保证系统休眠时仍能唤醒。
Android 12+ 兼容：
PendingIntent 必须加 PendingIntent.FLAG_IMMUTABLE 标志位。
在 API 31+ 上调度精准闹钟前，需检查 alarmManager.canScheduleExactAlarms()，若无权限降级为普通闹钟或引导授权。
Android 8.0+ 通知：AlarmReceiver 在发送通知前 必须先注册 NotificationChannel。
4. 后续演进规划 (Roadmap)
在保持大方向不偏离的前提下，后续版本可考虑添加的功能：
1.
数据备份与导出：支持导出 JSON 文件或导入恢复，方便更换手机。
2.
生物识别解锁：进入应用时支持指纹/面容解锁，保护卡号与备注隐私。
3.
桌面 Widget 小组件：在手机桌面显示近期即将到期的卡片列表。
